How to write a query

Beacon takes the words on their own, but it does considerably better if you tell it how they go together.

WriteAnd you get
lighthouse lamppages with either word, the ones with both first
lighthouse AND lamppages with both
lighthouse NOT museumthe first without the second
lighthouse NEAR lampboth, within ten words of each other
"night shift"the phrase, in that order
title:surveyonly the title line
host:swapmeet.comonly that host
lamp*lamp, lamps, lamplight

Worked example

  "night shift" AND host:riverbend-books.com NOT museum

reads as: the phrase night shift, on that one host, on pages that do not also talk about museums. Try it: run this query.

Things it will not do

  • Answer a question. It matches words; it does not read.
  • Rank by how good a page is. Only by how well the words fit.
  • Find a page nobody has linked to and nobody has submitted.
