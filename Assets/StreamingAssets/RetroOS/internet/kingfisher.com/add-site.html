Add a Site

Kingfisher is kept by hand. There is no robot, so a site gets listed when one of us has looked at it, which takes between four days and, in a bad week, a month.

What to send

LineWhat goes in it
Addressthe whole thing, with the host at the front
Titlewhat the site is called, not what it is about
Categoryone of ours, from the top page
Descriptiontwenty-five words. We will cut it to twenty.

What gets turned down

  • A page that is still being built. Send it when it is finished.
  • The same site under four addresses.
  • Anything whose description is in capitals.

Send it to the address at the foot of any page here. We read everything, eventually.
